ин основной проект: Issue / Task Tracker API

Один проект растёт вместе с навыком.

A · Pure JavaUser / Project / Task / Comment; JUnit с первого шага.
B · CollectionsFiltering / grouping / stats.
C · SQLSchema и запросы отдельно.
D · JDBCОдин DAO.
E · SpringController → Service → InMemoryRepo.
F · JPA/PostgresРеальная persistence.
G · QualityValidation, errors, filtering, transactions, Flyway.
H · SecurityПосле CRUD и tests: password hashing, 401/403, доступ к чужой задаче; без своего crypto.
I · TestsУглубление tests; unit с A, REST tests с E, PostgreSQL integration с F.
J · DeliveryDocker + Compose + CI.
Definition of done: без AI добавить endpoint, поле, migration, query, service logic, validation и test; затем объяснить весь flow.
