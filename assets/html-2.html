Основной roadmap

Каждый пункт: настройка, понимание темы или рабочее действие. Practice подтверждает конкретное выполнение; checkpoint — этап целиком.

SQL можно изучать после окружения параллельно Core; HTTP — после Fundamentals; Spring — после Core, Collections и HTTP. JVM/JDBC не блокируют старт Spring и отклики. Testing-фаза углубляет integration tests, unit tests начинаются в фазе 0.
Настройки — checklist с проверкой запуска. Темы — шкала понимания и применения; действия — шкала самостоятельного выполнения. Установка JDK/IDE/JUnit не повышает общий показатель освоения. Часы — учебный ориентир: самооценка сокращает объём максимум на 85%; только checkpoint закрывает фазу. Gate A/B считают необходимые фазы и зависимости, DSA и самостоятельность проверь отдельно.

Параллельные треки

DSA, SQL и интервью идут одновременно с основным маршрутом.

Algorithms / DSA

60–80 качественно разобранных задач.

ArraysStringsHashMap/SetStack/QueueTwo pointersSliding windowBinary searchTreesBFS/DFS

Неделя: 2 новые задачи текущего паттерна + 1 повтор через 2–7 дней. Отмечай mastery паттернов в ресурсах: галочка = повторно решил без подсказки, объяснил complexity и edge cases. После Arrays/Map переходи к two pointers; Trees/BFS позже.

SQL

SQLBolt → PostgreSQL → schema → CRUD → JOIN → aggregates → subqueries → indexes → EXPLAIN → transactions → JDBC → JPA.

Ориентир: 30–40 содержательных запросов. Неделя: 3 запроса текущей темы + повтор одного старого на своей schema; результат сверять на данных с NULL и пустыми связями.

Live coding

После функций и Collections (обычно с 3–4 недели): 1–2 раза в неделю по 30–40 минут без LLM/Copilot.

После решения: approach → complexity → edge cases → alternative.
