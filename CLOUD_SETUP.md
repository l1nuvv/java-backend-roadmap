# Supabase

Настройки выполняются владельцем через Supabase Dashboard и не показываются на сайте.

Для нового проекта последовательно выполните SQL из supabase/migrations. Для существующего проекта исходную миграцию повторять не требуется; усиление 202610060001_harden_progress.sql применено 06.10.2026 без удаления данных.

В Authentication → URL Configuration Site URL и Redirect URL: https://l1nuvv.github.io/java-backend-roadmap/.

Email-вход включён, подтверждение email включено, анонимный вход и регистрация новых пользователей выключены. Вход существующего аккаунта продолжает работать на разных устройствах. Для кода из письма можно добавить {{ .Token }} в шаблон Magic Link; стандартный шаблон содержит ссылку.

Public конфигурация находится в src/config.js. Изменив её, выполните npm run build и опубликуйте docs. Административные ключи в config.js и GitHub не добавляются.

Уже сохранённые локальные записи и cloud revision совместимы с версией 3.4. Экспорт, snapshots и auto-backup доступны для восстановления. Синхронизация проверяет облако каждые 15 секунд в видимой вкладке, при возвращении в приложение и при восстановлении интернета. Обновление токенов координируется через Web Locks между вкладками одного браузера. Выход передаётся другим вкладкам через storage event.

Проверка на реальной базе 06.10.2026 подтвердила RLS, запрет anonymous read/RPC, запрет прямой записи authenticated, отсутствие чтения чужих строк и отклонение некорректного payload. Проверка выполнялась с откатом транзакции.
